# RICCA DESIGNS — Мебельное ателье премиум-класса (Алматы)

Дизайнерский веб-сайт для мебельного ателье **RICCA DESIGNS** (Алматы, Казахстан). Сайт адаптирован на базе концепции и дизайн-системы *theidea.ru* с полной интеграцией айдентики, каталога, реальных отзывов и производственных стандартов бренда Ricca.

Сайт опубликован на **GitHub Pages**:
👉 **[Открыть сайт онлайн](https://stanix228-ops.github.io/ricca-designs/)**

## ✨ Особенности и функциональность
- **Главный экран (Hero):** 5 широкоформатных слайдов интерьеров с плавной анимацией текста и управлением.
- **Каталог бестселлеров:** Карточки моделей (SAVI, ELSEN, FLORIS, LUMO, CASE, KYOTO, CRYSTAL, MARKO) со свайпером и переключением ракурсов при наведении на пагинацию.
- **Карусель коллекций:** Обзор дизайнерских линеек мебели 2026 года.
- **Блок отзывов с 2ГИС:** Автоматическая плавная карусель отзывов реальных клиентов с паузой при наведении и возможностью ручного листания (тач/мышь).
- **Интерактивные модальные окна:**
  - Окно консультации и расчёта по индивидуальным размерам;
  - Окно «Задать вопрос дизайнеру»;
  - Корзина покупок с расчётом стоимости и сохранением в LocalStorage.
- **Полноэкранный поиск:** Мгновенный поиск по коллекциям и типам мебели.
- **Адаптивность:** Полная поддержка всех устройств (мобильные, планшеты, ультраширокие экраны).

---

## 🛠 Технологический стек
- **HTML5 & Modern CSS3:** Переменные CSS, Flexbox, CSS Grid, адаптивная верстка, микро-анимации.
- **JavaScript (Vanilla ES6+):** Модули управления слайдерами, корзиной, модальными окнами и поиском.
- **Swiper.js & Splide:** Сенсорные карусели и слайдеры.
- **Vector Icons:** Оптимизированный SVG.
